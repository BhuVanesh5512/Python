8. What is a `.pyc` file, and how is Python bytecode different from machine code?Explain what the cache is used for.
my answer : .pyc is a python bytecode file which has compiled module cache in it 
bytecode - is compiled code of python which can directly interpreted by python
machine code - this are native instructions which are executed directly in machine
profession answer :
.pyc file: Stores cached Python bytecode, usually under __pycache__/. It can save Python from having to recompile unchanged source on a subsequent import when the cache is valid.
Bytecode: Instructions for the Python virtual machine. It is not the same as native machine code.
Machine code: Native instructions executed by a processor.
Python source → compilation → bytecode → Python runtime executes bytecode
