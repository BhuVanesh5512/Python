7.Which version is better for a calculation function, and why?
A.def calculate_average(numbers):
    if not numbers:return None
    return sum(numbers) / len(numbers)
B.def calculate_average(numbers):
    if not numbers:raise ValueError("numbers cannot be empty")
    return sum(numbers) / len(numbers)
my answer : B, it raises the specific error ; sometimes None is better in some results
professional answer :
None means:"There is no result."
raise ValueError(...) means: "The caller supplied invalid input, so this operation cannot be performed."


'''
ValueError
→ correct general type, unacceptable value

TypeError
→ inappropriate type for the operation

return
→ successful result / normal function exit

raise
→ signal failure / abnormal exit

try
→ code that might fail

except
→ handles a matching exception

else
→ runs only when try succeeds

finally
→ runs regardless of success/failure

exception propagation
→ exception travels up the call stack until handled
