1. What is the difference between: [x * 2 for x in numbers] and {x * 2 for x in numbers}
my answer :[x * 2 for x in numbers] gives a list object  of numbers element doubles in order with duplicates
{x * 2 for x in numbers} gives a set object of numbers elements doubles without duplicates
professional answer :
[x * 2 for x in numbers] creates a list containing the transformed values in iteration order, and duplicate values are allowed.

{x * 2 for x in numbers} creates a set containing the transformed values, so duplicate values are removed.


2.what is the difference between : [x for x in numbers if x > 5] and [x if x > 5 else 0 for x in numbers]
my answers : [x for x in numbers if x > 5] gives a list object of numbers element which are filter bt condition of if.
[x if x > 5 else 0 for x in numbers] gives a list object of numbers elements, here we iterate over every element and base on condition awards what value to be in list
#The first can remove elements; the second produces one output for every input element.
professional answer :
[x for x in numbers if x > 5] is a filtering comprehension. It keeps only the elements that satisfy the condition, so some input elements may be excluded.

[x if x > 5 else 0 for x in numbers] processes every element and chooses which value to produce based on the condition. Therefore, every input element produces one output element.
