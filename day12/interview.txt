-> Why should we use with open() instead of manually opening and closing the file?
We use a context manager through with open() to manage the file's lifecycle.
 It guarantees that the file is properly closed when execution leaves the block, including when an exception occurs. 
This prevents resource leaks
->Suppose __exit__() returns True. Does it mean the exception never happened, or does it mean something else?
Returning True from __exit__() suppresses the exception, preventing it from propagating beyond the context manager. 
This should only be done when the context manager can safely handle or intentionally ignore that particular exception.

    cleaned_prompts = []
    all_valid = True
