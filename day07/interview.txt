1.What is the difference between:parameter argument return
my answers :
parameter : parameter are name placeholder which are defined with function
argument : arguments are values/name references of value object  which we supplied to function
return : keyword which help to return to function call 
professional answer :
Parameter: a named placeholder defined in a function definition.
Argument: the actual value/object supplied when the function is called.
Return: the return statement sends a value from the function back to the caller and immediately exits that function.
